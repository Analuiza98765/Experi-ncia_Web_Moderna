# Biblioteca Digital UniFECAF

Projeto acadêmico desenvolvido na disciplina de **Design Web**, com o objetivo de transformar um protótipo de baixa fidelidade em uma interface web moderna, responsiva e alinhada à identidade visual da UniFECAF.

O site apresenta uma proposta de biblioteca digital para facilitar a visualização de livros, categorias e informações sobre os serviços da biblioteca.

## Acesso ao projeto

- **Site publicado:** [Biblioteca Digital UniFECAF](https://analuiza98765.github.io/Experi-ncia_Web_Moderna/)
- **Repositório:** [GitHub](https://github.com/Analuiza98765/Experi-ncia_Web_Moderna)

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e das seções da página.
- **CSS3:** estilização, organização do layout e adaptação para diferentes tamanhos de tela.
- **GitHub Pages:** publicação e acesso ao site pela internet.

## Estrutura do projeto

```text
Experi-ncia_Web_Moderna/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── relatorio-biblioteca-unifecaf.pdf
```

- `index.html`: contém a estrutura e o conteúdo da página.
- `css/style.css`: reúne os estilos visuais, as cores, a tipografia, os espaçamentos e as regras de responsividade.
- `assets/imagens/`: armazena as imagens utilizadas no site.
- `relatorio-biblioteca-unifecaf.pdf`: apresenta a análise do projeto e as decisões adotadas no desenvolvimento.

## Principais características

- Interface baseada na estrutura do protótipo de baixa fidelidade.
- Identidade visual inspirada nas cores institucionais da UniFECAF.
- Organização do conteúdo em seções para facilitar a navegação.
- Apresentação visual dos livros por meio de cards e imagens.
- Layout responsivo para computadores e smartphones.
- Separação entre a estrutura HTML e os estilos CSS.

## Como visualizar localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

```bash
git clone https://github.com/Analuiza98765/Experi-ncia_Web_Moderna.git
```

O projeto utiliza HTML, CSS e imagens locais, sem necessidade de instalar dependências para visualizar a página.

## Observações

Os livros e seus títulos são ilustrativos e foram utilizados para demonstrar a proposta visual da biblioteca digital. As informações poderão ser substituídas por dados reais do acervo, caso sejam disponibilizados pela instituição.
