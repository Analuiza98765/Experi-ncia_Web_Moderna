# Biblioteca Digital UniFECAF — Projeto de Design Web

Projeto acadêmico desenvolvido com HTML e CSS, com foco em organização visual, responsividade e acessibilidade básica.

## Estrutura
- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: estilos, paleta UniFECAF e regras responsivas para computadores e celulares.
- `assets/imagens/`: imagens locais usadas no destaque, no acervo e nas seções da biblioteca.
- `relatorio-biblioteca-unifecaf.pdf`: análise do projeto, decisões visuais, acessibilidade, responsividade e capturas de desktop e smartphone.

## Identidade visual
A interface usa azul-marinho e azul como cores institucionais de base, com verde nos destaques e chamadas para ação, conforme a referência visual da UniFECAF. As imagens ficam no próprio projeto para que a página não dependa de serviços externos para carregá-las.

## Como visualizar
Abra o arquivo `index.html` em um navegador. O site usa HTML, CSS e imagens locais e pode ser visualizado sem conexão com a internet.

## Observação
Os livros e seus títulos são ilustrativos, usados para demonstrar a interface. Substitua-os por informações reais do acervo caso a instituição forneça esses dados.
